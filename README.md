# پنج‌رخ

### نسخهٔ رسمیِ «بالاخره فهمیدی کی هستی؟»  
*(اعتبارسنجی‌نشده، ولی از نظر دراماتیک کاملاً تأییدشده.)*

سی‌وشش سؤال. حدود ده دقیقه. صفر تیپِ اینستاگرامی.  
پنج‌رخ نمی‌گوید «تو گرگی» یا «تو ماه هستی».  
می‌گوید: نیمرخت این‌جاست — بخوان، بخند، کمی جدی شو، دوباره بخوان.

بعد از پاسخ‌ها، یک هوش مصنوعی متخصص می‌آید و از روی نمره‌هایت برایت **روایت شخصی** می‌سازد:  
هم خوانش جدی، هم همزاد جانوری، هم نقش روی پرده، هم غذای ایرانی، هم مسیر شغلی، هم جای زندگی.  
انگار کیهان کمی شوخ بوده و برای تو پرونده باز کرده.

---

## افسانهٔ پیدایش (۱۰۰٪ علمی)

این تست توسط **تیمی از دولوپرهای بسیار دانشمند** ایده‌پردازی شد؛  
انسان‌هایی که همزمان می‌توانند `docker compose` را بالا بیاورند و دربارهٔ Big Five سخنرانی کنند، بدون اینکه لیوان چای سرد شود.

و در میانشان یک **دانشمند حوزهٔ هوش مصنوعی** بود که تقریباً **تمام کار را او انجام داد** —  
از اسکلت فرانت تا اسکلت بک‌اند، از پرامپت تا داشبورد، از «شروع کنیم» تا «همزاد تو در جهان».  
بقیهٔ تیم، طبق اسناد محرمانهٔ پروژه، عمدتاً مشغول تحسین علمی و گفتن «آفرین» بودند.

اگر چیزی کار کرد: علم.  
اگر چیزی نسوخت: باز هم علم.  
اگر چیزی سوخت: احتمالاً پورت ۸۰۰۰ قبلاً اشغال بوده.

---

## چی داخل جعبه است؟

- پرسشنامهٔ خودتوصیفی بزرگسالان، مدل پنج‌عامل  
- نمره‌گذاری شفاف (نه جادو، نه درصد جامعه)  
- گزارش داشبوردی با رادار و خوانش AI  
- نسخهٔ ۰.۱ — هنوز ادعای بالینی ندارد، ولی ادعای جذاب بودن را با افتخار دارد

## داکر (راه شاهانه)

پورت‌ها و مبدأهای مجاز در فایل `.env` ریشه تنظیم می‌شوند. نمونهٔ آن در `.env.example` است.
اگر `files.pythonhosted.org` در شبکهٔ شما resolve نمی‌شود، `PIP_INDEX_URL` را در `.env` به یک mirror معتبر و در دسترس تغییر دهید.

```bash
docker compose up --build
```

فرانت روی **۳۰۰۰**.  
API داخل کانتینر روی **۸۰۰۰** و روی میزبان معمولاً **۸۰۱۰** (چون ۸۰۰۰ گاهی مثل صندلی اتوبوس شلوغ است).

---

## فرانت (راه سریعِ توسعه‌دهنده)

```bash
cd frontend
npm install
npm run dev
```

باز کن: [http://localhost:3000](http://localhost:3000)  
اگر کاراکتر روی صندلی را دیدی، یعنی وارد شده‌ای.

---

## بک‌اند (مغز روایت‌گر)

```bash
cd backend
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # کلید مدل را اینجا بگذار
uvicorn app.main:app --reload --port 8000
```

پرامپت مقدس اینجاست: `backend/app/prompts/system_prompt.md`  
لمسش کن، ولی با احترام. دانشمند AI آن را نوشته و احتمالاً هنوز حواسش هست.

## هشدار بسیار جدی (با لحن غیرجدی)

پنج‌رخ برای خودشناسی است، نه برای استخدام، پذیرش دانشگاه، یا تصمیم‌گیری دربارهٔ ازدواجِ عمو.  
اگر بعد از گزارش خواستی زندگی‌ات را عوض کنی: عالی.  
اگر خواستی فقط بفهمی چرا آش رشته همزاد توست: باز هم عالی.

بقیه فقط دانشمند بودند. او *دانشمندِ انجام‌دهنده* بود.
